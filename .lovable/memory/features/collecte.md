---
name: Plannings de collecte par prestation
description: Chaque catégorie affiche son info de collecte ; pas de champ lieu, dépôt toujours à l'accueil
type: feature
---
Chaque catégorie de service a un champ `pickup_info` affiché dans /reserver :
- Pressing : collecte tous les jours à 10h
- Retouches : collecte le mercredi à 10h
- Cordonnerie : collecte le mardi et vendredi à 10h
- Colis : dépôt/retrait à l'accueil aux horaires d'ouverture

Pas de champ « lieu de dépôt » dans le formulaire de réservation : après la réservation, un message indique « nous attendons vos affaires à l'accueil » (toast + encart sur la page paiement).
